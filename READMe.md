CyberSaathi – Smart Digital Safety and Cyber Fraud Awareness

1. About the Project

CyberSaathi is a digital safety and cyber fraud awareness platform designed to help citizens identify suspicious links, recognize online scams, and stay safe in the digital world.

The application provides risk alerts, cyber safety tips, and awareness about phishing, fake KYC messages, and online fraud.

2. Problem Statement

Many people are affected by cyber fraud due to a lack of awareness about suspicious links, fake messages, phishing attacks, and online scams. CyberSaathi aims to provide a simple and accessible solution to help users recognize potential threats and make safer online decisions.

3. Features

- Suspicious Link Checker
- High-Risk and Low-Risk Alerts
- Cyber Fraud Awareness
- Cyber Safety Tips
- User-Friendly Interface
- Clear Button to reset the input
- Educational information about online scams

7. How to Run the Project

Step 1: Download the Project

Clone the repository using:

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the Project

Open the CyberSaathi project folder in Visual Studio Code.

Step 3: Run the Frontend

Open the HTML file in a web browser or use the Live Server extension in Visual Studio Code.

Step 4: Run the Java Backend

Open the backend folder in your code editor.

Compile and run the Java backend according to its configuration.

For a plain Java project:

javac Main.java

java Main

For a Spring Boot project, use:

mvn spring-boot:run

Note: Use the command that matches your actual Java backend.

Step 5: Test the Application

1. Open CyberSaathi in your browser.
2. Enter a sample URL in the Link Checker.
3. Click Check Safety.
4. Observe the risk alert displayed.
5. Test both high-risk and low-risk sample URLs.
6. Click Clear to reset the input.
